## 4. 항목별 재점검 체크리스트

재점검은 기존 점검 이력을 유지하기 위해 WSCAN의 **[이슈 처리하기] → [재점검하기]**로 수행한다. **[전수 분석]은 실행하지 않는다.**

- [ ] 수정본이 `https://ux.snu.ac.kr`에 배포되었고 배포 커밋과 일시를 기록했다.
- [ ] 레거시 URL 2개가 모두 정상 응답하며 현재 게시물 주소로 이동한다.
- [ ] 대표 HTML에서 외부 실행 스크립트, 활성 HTTP 리소스, 원문 이메일, 비활성 임베드 키가 검출되지 않는다.
- [ ] 대표 정적 파일의 확장자, `Content-Type`, 응답 상태를 확인했다.
- [ ] 7개 직접 조치 규칙을 각각 선택하여 항목별 재점검을 실행했다.
- [ ] 직접 조치 7개 규칙의 재점검 결과를 규칙명별로 저장했다.
- [ ] 응답 헤더 관련 6개 규칙에 대해 `github-pages-exception-draft.md`를 공식 조치 불가 사유서 양식으로 옮겨 첨부했다.
- [ ] 6개 규칙 각각에 `Server: GitHub.com`, `Cache-Control`, 누락 헤더 및 대체 통제 증빙을 연결했다.
- [ ] 13개 규칙 모두에 처리 상태가 지정되어 WSCAN의 `[미지정]` 항목이 0건임을 확인했다.
- [ ] 최종 WSCAN 결과 내보내기 파일과 화면 캡처를 저장했다.
- [ ] 완료 메일에 조치 결과, 사유서, 재점검 증빙을 첨부했다.
