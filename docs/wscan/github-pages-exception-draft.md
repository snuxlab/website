## 1. 누락 또는 부적절한 Referrer-Policy 헤더 (81건)

### 조치 불가 사유

`Referrer-Policy`는 HTTP 응답 헤더로 설정해야 하나, 대상 서비스는 GitHub Pages 공유 엣지에서 응답을 제공한다. 저장소 설정이나 정적 파일만으로 GitHub Pages가 생성하는 해당 응답 헤더를 추가·변경할 수 없다. 이는 비용이나 조치 일정의 문제가 아니라 외부 호스팅 서버에 대한 설정 권한 부재로 인한 기술적 제약이다.

### 적용한 대체 통제

- 모든 공통 HTML 문서에 `strict-origin-when-cross-origin` 메타 리퍼러 정책을 적용한다.
- 인증 토큰, 세션 식별자, 개인정보 등 민감한 값을 URL 쿼리 파라미터로 사용하지 않는다.
- 외부 실행 스크립트와 불필요한 외부 리소스를 제거하여 외부 전송 가능성을 줄인다.

### 제출 증빙

- `Server: GitHub.com` 응답: `[파일명/캡처]`
- `Referrer-Policy` 응답 헤더 확인 결과: `[파일명/캡처]`
- 배포 HTML의 메타 정책: `[파일명/소스 위치]`
- 민감한 URL 파라미터 미사용 확인: `[검사 결과]`

## 2. 잘못된 캐시 통제 (81건)

### 조치 불가 사유

`Cache-Control` 값은 GitHub Pages 공유 엣지가 관리하며 저장소 소유자에게 임의 캐시 정책 설정 권한이 제공되지 않는다. 정적 HTML이나 저장소 설정으로 GitHub Pages의 응답 캐시 정책을 덮어쓸 수 없다. 이는 비용이나 조치 일정의 문제가 아니라 외부 호스팅 서버에 대한 설정 권한 부재로 인한 기술적 제약이다.

### 적용한 대체 통제

- 사이트는 누구나 열람 가능한 공개 정적 콘텐츠만 제공한다.
- 로그인, 사용자 세션, 결제, 개인정보 입력·조회 및 사용자별 응답을 제공하지 않는다.
- 인증 정보나 개인정보를 HTML·JavaScript 응답에 포함하지 않는다.
- 따라서 공유 캐시에 저장되어 기밀성이 훼손될 동적·개인화 응답이 존재하지 않도록 서비스 범위를 제한한다.

### 제출 증빙

- `Server: GitHub.com` 응답: `[파일명/캡처]`
- 실제 `Cache-Control: [정확한 응답값]`: `[파일명/캡처]`
- 정적 사이트 구성 및 동적 기능 부재 확인: `[구성 파일/화면 목록]`
- 로그인·세션·개인정보 입력 기능 부재 확인: `[확인 자료]`

## 3. 누락된 CSP 헤더 (79건)

### 조치 불가 사유

`Content-Security-Policy`는 HTTP 응답 헤더로 적용해야 하나, GitHub Pages 공유 엣지가 응답 헤더를 생성하며 저장소 소유자가 임의 CSP 응답 헤더를 추가할 수 없다. 이는 비용이나 조치 일정의 문제가 아니라 외부 호스팅 서버에 대한 설정 권한 부재로 인한 기술적 제약이다.

### 적용한 대체 통제

- Google Analytics와 공유 위젯 등 외부 실행 스크립트를 제거한다.
- 필요한 JavaScript, CSS, 글꼴 및 아이콘을 동일 출처에서 자체 호스팅한다.
- 이메일과 Bot Framework 임베드 키가 있던 비활성 주석을 삭제한다.
- 사용자 입력을 서버에서 처리하거나 요청값을 HTML에 반영하는 동적 경로를 제공하지 않는다.

### 제출 증빙

- `Server: GitHub.com` 응답: `[파일명/캡처]`
- CSP 응답 헤더 확인 결과: `[파일명/캡처]`
- 외부 `<script src>` 0건 검사 결과: `[로그 파일]`
- 정적 자산 동일 출처 제공 및 주석 속 키 삭제 검사 결과: `[로그 파일]`

- 배포되는 파일은 관리자가 저장소에 등록한 정적 파일로 제한한다.
- 배포 후 대표 HTML, CSS, JavaScript, 글꼴 및 이미지 파일의 확장자와 `Content-Type` 일치를 확인한다.

- 프레임을 통한 UI 오도 발생 시 공격자가 대신 수행할 수 있는 민감한 사용자 행위가 존재하지 않도록 기능 범위를 제한한다.

### 적용한 대체 통제

- 서버 측 애플리케이션과 데이터베이스가 없는 정적 사이트로 운영한다.
- 요청값 또는 사용자 입력을 HTML에 반영하는 동적 경로를 제공하지 않는다.
- 외부 실행 스크립트를 제거하고 필요한 스크립트는 동일 출처에서 제공한다.
- 소스와 생성 HTML에서 노출된 이메일 및 비활성 임베드 키를 제거한다.
